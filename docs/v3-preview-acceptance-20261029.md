# V3 计次与计时习惯：预览阶段验收

## 本次提交范围
- 只在 DEV 与独立预览路径显示新增组件，正式站 main 未改变。
- 可创建计次/计时习惯，填写每日目标；同一天可以重复记录数值。
- 使用 `record_progress_v3`，每笔新记录具有独立 operation_id 与 event_id。
- 可查看当日每笔时间与数值、执行撤销；撤销通过同一事件的 revision 写入，不执行物理删除。
- 显示累计值与记录笔数，云端请求完成后重新读取，不伪造保存成功。
- 若服务端没有 V3 RPC，只提供升级提示，不会写入旧 schema。
