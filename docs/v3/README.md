## 需要批准的产品取舍

1. 新增 Emoji、排序、类型/目标/单位五列；保留原两表，增加 **一张不可变数值操作表**及一张每日最新值视图，无增量同步体系。
2. 第一版类型/目标/单位创建后固定。变更目标需归档并新建，不重新解释旧历史。
3. 计时为整数分钟（目标/实际最多 1440）；计数为整数次数（最多 1000000），不支持公斤、公里或复合单位。
4. Emoji 为十个精确 Unicode 预设，默认 🌱；不接受任意字符串、变体或 HTML。
5. 排序以完整活跃 ID 列表做值比较的 CAS，最多 500 项；不额外增加全局同步版本表。
6. 徽章按每个习惯计算，而非全 App 任意完成一项即算连续。徽章根据完整、当前可信历史派生：普通断签保留历史成就；主动修正获奖历史后可能撤回。如果要求修正后仍永久保留，需另审解锁事件表，本草案没有声称实现不可撤销徽章。
7. 旧云端客户端仍只显示 Boolean，不能正确展示 V3 数值目标。部署阶段 3 前必须告知此范围；不是完整 V3 客户端兼容。

本阶段不接入新前端、不执行远程 SQL、不修改 Auth/Data API、不发布任何网站。
