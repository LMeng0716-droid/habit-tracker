## CI 失败根因与修复

用户提供的 run 39186193165 日志：46 passed / 4 failed / 2 skipped，PWA及会话reload组等待“阅读”超时。`login()`只等待点击提交，不等待异步signInWithPassword、会话持久化和云端首批数据；失败组在点击后立即reload，可中断未完成登录。其他先等首页再刷新的测试没有该缺陷。

修复只在测试中明确等待云端“阅读”卡片出现，再reload并保留所有恢复/过期/隔离断言。新增生产和预览两项目的受控Auth门闩：token响应未释放时没有卡片、没有session-policy，点击返回并不表示登录成功；释放后卡片和policy就绪，刷新后仍恢复。没有修改Auth安全逻辑、延长超时、skip或删除测试。SDK/网络是真实异步机制，token是fixture，不是真实SupabaseJWT。

首次本地全量又捕获一个既有动画竞态（51 passed / 1 failed / 2 skipped）：原用例在布局检查后读取1.2秒动画节点，节点已被定时器卸载，animationName为空。修复将**该测试**的时钟暂停，保留动画名、粒子数、可见位置断言，再显式推进1200ms验证移除。没有延长产品动画。最终完整重跑52 passed / 2 skipped。
