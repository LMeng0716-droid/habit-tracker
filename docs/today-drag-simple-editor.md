# 手机云端版：今日排序与极简编辑

基于已审核构建 a3b12fb 修订，不修改 Supabase 数据库。

- 「今天」卡片左侧直接出现 ☰ 排序手柄。触屏按住拖到另一张卡片，鼠标拖动或键盘上下方向键亦可排序，结果调用现有 reorder_habits RPC 保存至云端。
- 「账号 → 编辑习惯」仅保留习惯列表，不再在账号页显示排序手柄。
- 选择习惯后只显示「名称」和「Emoji（手机键盘输入）」；移除无实际用途的颜色输入框。
- 编辑页底部只有「保存修改」「归档」「取消」三个按钮。「保存修改」仅当名称或 Emoji 改动时启用，并统一执行变更。
- 现有 API 的 edit_habit 与 set_habit_emoji 为两个独立请求；同时修改名称与图标时，非原子操作。发生网络错误时保留输入并要求刷新核对，防止悄悄丢失改动。
- 历史打卡、累计统计、归档恢复不改变；正式版 main 与 V3 沙盒不改变。
