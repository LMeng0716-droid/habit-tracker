# 手机端庆祝反馈修复

## 基线与根因

以远程开发分支 57ecd52 为基线（它与此前导出的 684863c 文件树一致）。原普通成功提示仅显示在文档顶部，滚动到下方习惯时看不到；按钮缩放 1.12 倍/450ms 太轻；全完成只有顶部提示和单组星星缩放。日期级 localStorage 标记还会屏蔽当日再次完成的反馈，多个习惯共用清理定时器也不适合并发反馈。

## 本次修改

- 保留服务器成功确认及账号 epoch/操作序号保护。成功且该日从未完成变为完成时才触发今天的庆祝；取消、失败、仅对账成功、历史日期写入和纯快照读取均不触发。
- 卡片名称下方显示“完成啦！✨”，配合 5 颗轻量星星及更明显的对勾弹跳，约 1.1 秒；每个习惯单独计时，重复完成通过新序号重新播放，不重建可聚焦的按钮。
- 固定视口成功提示根据目标卡片位置显示在另一侧（顶部安全区或底部导航上方），避免遮住刚操作的卡片，包含习惯名和云端确认信息；CSS pointer-events:none，粒子为 aria-hidden，不拦截触控或键盘操作。卡片提示在正常文档流中。
- 最后一个有效习惯经确认完成，从“未全部完成”变为“全部完成”时，播放 22 颗绿色/奶黄色星星撒花与“今天的目标全部完成！🌱”，约 2.1 秒。只使用 transform/opacity 动画，无动画库、离线队列或 Service Worker。
- 不再按日期永久去重：取消后再次成功完成是新状态跃迁，允许再播放。纯刷新、历史加载、切账号不进入确认写入路径，因此不会重复触发。旧 localStorage 庆祝键不读、不写、不删除，Auth 和旧业务键不变。
- 预览 Base 或本地开发模式的账号页有“预览庆祝效果（不会打卡）”。明确显示“效果预览 · 不会打卡或保存数据”，不显示云端保存成功，不调用 RPC、不清理存储；正式 Base 的生产构建不提供该按钮。
- 减少动态效果时隐藏粒子、禁用动画，保留同样时长的静态成功文字。会话期限、RPC、数据模型、失败回滚流程不变。

## 验证范围

单元测试覆盖新完成/重复响应/取消/再次完成/最后一个习惯/历史/跨日和显示时长。浏览器测试覆盖普通及全完成、低位置卡片可见性、服务器确认前无庆祝、失败/不确定响应无庆祝、快速连续请求、历史读取、刷新、账号切换、减少动态效果、旧标记不影响且原样保留，以及效果预览无写入。

本地浏览器与 API fixture 不代表真实 iPhone/Supabase 验收。真实 iPhone PWA 尚需用户更新预览后验证：滑到底部完成一项、取消后重做、完成最后一项、账号页预览、开启“减少动态效果”；确认消息清晰、操作不中断。无需修改数据库或 Auth 配置，无需清除站点数据。

并发补充：若刷新先读到数据库已提交的完成状态，但写入 RPC 响应仍在路上，庆祝判断使用该操作开始时的快照，避免被早到的读取吞掉；今天还有其他未确认操作时暂不发全完成反馈，等最后一个成功响应。新增模拟测试专门复现此顺序。
