# 第一版实现与验收记录

日期：2026-10-09（北京时间）。开发分支：`feat/daily-progress-v1`。

## 已实现范围

按三份调研/规划文档独立实现 React + TypeScript + Vite 单页应用。已完成新建/编辑、每日打卡/撤销、月历补记确认、当前与历史最长连续、累计/月完成率、归档历史只读/删除、JSON导出/预览后替换导入、清空确认、损坏数据恢复、存储错误和多标签冲突保护。

中文界面采用原创CSS、文本符号和系统字体，不复制参考项目代码、Logo或图片；不添加账户、云数据库、分析追踪或部署。日历按真实本地日期记录，内部日历运算与设备“今天”分离。月份筛选不改变历史最长连续。

## 当前机器实际验证

环境：Node24、npm11，系统Chromium；Playwright自动浏览器验收。测试浏览器时区设置为Asia/Shanghai；单元测试另在Asia/Shanghai和America/New_York执行。

| `npm test` | 27项通过 | 日期/跨月跨年/闰年/DST日历运算、连续、归档、月统计、备份校验、损坏与冲突存储 |

浏览器验收场景：

1. 新建、编辑、打卡、刷新保留、撤销、导出、清空、恢复JSON。
2. 月历先选日期再确认补记/撤销、跨月最长连续、月完成率、未来/创建前禁用、浏览器返回。
3. 归档原子移除当天记录、保留历史、只读、删除取消与确认。
4. 未知版本备份拒绝，合法备份取消不修改现有数据。
5. 损坏存储保留原文，禁止普通修改，从校验备份恢复。
6. 写入配额失败不展示伪成功，不改变原数据，仍可导出。
7. 第二窗口修改导致第一窗口只读，刷新读取新状态。
8. 360px宽度首页与月历无水平溢出；名称校验、弹窗初始焦点/关闭后焦点恢复、未保存退出提示。
9. 本地午夜切换今天，昨天结束的连续仍保留。
10. 初始化存储不可写时已有记录不丢失，导出仍包含原记录。
11. ID生成不依赖仅secure-context可用的randomUUID，支持局域网HTTP预览使用的随机数接口。

测试曾发现弹窗初始与返回焦点问题，已修正并在完整11条回归中通过。单元测试还验证50个习惯、730天、共36500条记录的备份解析；没有做大规模浏览器性能基准。

## 未验证和明确限制

- iPhone Safari、实际Android设备与Firefox：**未验证**；已做Chromium360px手机宽度模拟，不能替代真实设备。
- 多写者极端同时提交：不支持实时协作；已有storage事件和写前快照检查，建议一个标签页编辑。
- 不支持归档恢复、暂停区间、周频率、多次/计量目标、自动跨设备同步或PWA离线。
- GitHub Actions工作流已添加，本机对应命令通过，但远程Actions执行情况需看PR/仓库检查，不能提前宣称通过。
- 本次没有部署、合并PR或发布站点。
