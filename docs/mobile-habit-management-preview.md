# 手机云端版：习惯管理（本机偏好预览）

该分支基于已发布且通过验证的手机预览源码 `da2b5a3`，包括此前的恢复归档、累计打卡与最长连续统计修复。

## 云端功能（保留原有 API）

- 创建、编辑习惯名称和颜色；归档和恢复；打卡、历史查询。
- 这些业务数据仍使用 `habit_mobile` 的 RPC 和 RLS 策略。

## 仅保存在本机浏览器

- Emoji 图标从预设列表中选择。
- 习惯排序：上移、下移，或在触屏设备长按手柄拖到另一张习惯卡片。
- 偏好存储在本机 localStorage，按 Supabase 项目 URL、部署路径和用户 ID 隔离，不会上传或覆盖云端打卡记录。
- 清除站点数据、切换设备、浏览器或安装位置，可能导致偏好恢复默认值。
- 保存失败会显示警告，不会伪称已保存成功。

## 后续需要单独批准的云端升级

若需要跨设备同步图标和排序，必须先审核 `habit_mobile.habits` 的新增列、校验规则和拥有者受限的 RPC。当前分支没有修改任何数据库结构，也未运行 SQL。

已在手机登录态切换前初始化本机偏好，避免条件渲染时出现 Hook 调用顺序变化。
